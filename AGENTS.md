# Agent Guidelines

## Git Rules
- **Never run `git` commands** (`init`, `add`, `commit`, `push`, `reset`, etc.) unless explicitly asked.
- After changes, propose a commit message based on `COMMIT_SCOPES.md` only when a commit is appropriate.

## General Rules
- Default to feedback and discussion only; do not modify files unless explicitly instructed to do so.
- Code must always stay aligned with `concept.md` and `achievements.md`.
- Do not invent extra wording or unrequested content in `concept.md`; keep it precise, concise, and readable.
- Always avoid editing character files or world files to prevent any risk of save corruption.
